== Description ==

Take full control of your WooCommerce variation products with Variation Monster, the all-in-one plugin that transforms how customers interact with product variations. 

Packed with powerful features like color and image swatches, variation tables, quick cart carousels, tooltips, quick view popups, custom discount badges, and gallery layouts, this plugin gives you total design freedom — no coding required. 

Variation Monster includes everything you need to enhance variation UX: 

   - **Variation Swatches for WooCommerce:** replace boring dropdowns with beautiful color, image, and label swatches. 
   - **Variation Table for WooCommerce:** display all variations in a table layout for faster selection and comparison. 
   - **Variation Gallery for WooCommerce:** assign separate image galleries to each variation with multiple style templates. 
   - **Quick View for WooCommerce:**  let customers view full product details and variation options in a popup window. 
   - **Variation List Templates:** choose from flexible layouts to showcase variations with titles, prices, SKUs, and badges. 
   - **Quick Cart Carousel:** allow variation selection and add to cart directly from the shop or archive pages. 

All features are fully customizable from the settings panel or per product — making Variation Monster the ultimate variation management plugin for WooCommerce stores of all sizes.

== Installation ==
1. Upload the Plugin Files: Upload the Variation Monster folder to the `/wp-content/plugins/` directory.
   2.Activate the Plugin: Activate the plugin through the \'Plugins\' menu in WordPress.
3. Install Required Plugins: Make sure WooCommerce is installed and activated.
4. Configure the Plugin: Go to \'Variation Monster\' Settings\' under Product Menu to configure the plugin

##Frequently Asked Questions

###  What is Variation Monster Pro?
    Variation Monster is an all-in-one WooCommerce plugin that enhances how product variations are displayed and interacted with. It replaces default dropdowns with     swatches, tables, galleries, quick cart carousels, and more—making variation shopping faster and more visual.

###  Can I use both variation swatches and variation table together? 
     Yes! Variation Monster allows you to use swatches and the variation table simultaneously. You can choose how to display variations globally or on a per-product         basis using flexible layout settings.

### Is the plugin compatible with all WooCommerce themes?
    Variation Monster is built to work with most standard WooCommerce themes. However, for custom themes, minor CSS adjustments may be needed for perfect styling.

### Does this plugin support color, image, and label swatches?
    Absolutely. You can create color swatches, upload custom images, or use text/label swatches to represent product attributes visually on both single product and     archive/shop pages.  

### Can I display variation image galleries separately for each variation?
    Yes! The Variation Gallery feature allows you to assign multiple images to each product variation, and display them using different gallery templates.

### How do I enable Quick View or Quick Cart Carousel?
    You can enable these features from the plugin settings panel. They allow customers to view product details or add variable products to the cart without leaving the     shop/archive pages. 

### Does this plugin work with variable products only? 
    Yes. Variation Monster is designed specifically for variable products in WooCommerce and adds advanced display options for attributes and variations.  

### Can I customize discount badges and variation list templates?
    Yes. You can fully customize discount badges (flat or percentage), badge text, background colors, and choose from multiple list templates to match your store's     design.

### Is this plugin mobile responsive?
    Absolutely. All components—including swatches, variation tables, lists, and galleries—are fully responsive and optimized for mobile and tablet devices. 

###  Does Variation Monster require coding knowledge to use?
     No coding required! The plugin comes with a user-friendly admin panel where you can control every feature with simple toggles, dropdowns, and input fields. 

###  Does Variation Monster work with Dokan plugin?
     Yes! It's fully compatible with Dokan multivendor plugin. Form version 1.0.0 our both plugin free & pro fully compatible with Dokan plugin.
